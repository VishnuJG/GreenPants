# Privacy Policy for URL Path & Params Editor

**Last Updated:** November 18, 2024

## Overview

URL Path & Params Editor is a Chrome extension that allows users to edit URL components in a visual interface. We are committed to protecting your privacy.

## Data Collection

**We do NOT collect, transmit, or share any user data.**

### What Data is Stored Locally

The extension stores the following data **locally on your device only** using Chrome's storage API:

- **URL History**: URLs you have copied or navigated to (up to 20 most recent)
- **Path Suggestions**: Path segments you have used (up to 30)
- **Parameter Suggestions**: Query parameter keys you have used (up to 30)

### Important Points

- ✅ All data is stored **locally on your device**
- ✅ **No data is transmitted** to any external servers
- ✅ **No data is shared** with third parties
- ✅ **No analytics or tracking** of any kind
- ✅ You can clear all stored data at any time using the "Clear History" and "Clear Suggestions" buttons

## Permissions

The extension requires the following permissions:

### activeTab
- **Purpose**: To read the current tab's URL when you open the extension
- **Usage**: Allows you to edit the URL of the page you're currently viewing

### storage
- **Purpose**: To store URL history and suggestions locally on your device
- **Usage**: Provides quick access to previously used URLs and path segments

## Data Retention

- All data is stored locally on your device
- Data persists until you manually clear it using the extension's clear buttons
- Uninstalling the extension automatically removes all stored data

## Changes to Privacy Policy

We may update this privacy policy from time to time. Any changes will be reflected in the extension's updated version.

## Contact

For questions or concerns about this privacy policy, please contact us through the Chrome Web Store support page.

## Your Rights

You have the right to:
- View all data stored by the extension (stored in Chrome's local storage)
- Clear all data at any time using the extension's built-in clear functions
- Uninstall the extension to remove all stored data

---

**Summary**: This extension stores URL history locally on your device only. No data is collected, transmitted, or shared with anyone.
